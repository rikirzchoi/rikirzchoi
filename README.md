### 🔧 Building

- **[calyx-systolic-generator](https://github.com/rikirzchoi/calyx-systolic-generator)**: took a naive 4×4 matrix multiply and turned it into a pipelined systolic array in Calyx IR, verified with Verilator cycle-accurate simulation (**804 → 55 cycles**)
- **Mini-TPU on FPGA** *(in progress)*: a systolic-array accelerator in Verilog, targeting an int8 MLP running end to end on a PYNQ-Z2

### 🔬 Research

- **ML compiler cost models**: graph neural networks for predicting latency on Google's TPUGraphs dataset (Boston University)
- **EvolveBench**: a benchmark of whether web agents actually improve with experience (Stanford, remote)
